## MODIFIED Requirements

### Requirement: Showing the folder
`F` in the library's "Books", "Show the Books folder" ("Показать папку «Книги»") in the empty library, "Show" beside the
Books folder in the settings (`settings`) and, on macOS, File › Show the Books Folder SHALL open the folder in Finder on
macOS and in the default file manager on Linux.

#### Scenario: Where are my books
- **WHEN** the reader presses `F` in the library
- **THEN** the Books folder opens in the file manager
