The first public release of Forzac for desktop: an offline reader for FB2, FB3 and EPUB books with the typesetting of
a good printed book — hyphenation in Russian and English, justified lines, no lone lines at page edges — for Linux and
macOS. Keyboard first, few settings, free. The desktop sibling of [Forzac for Android](https://forzac.truenrth.app).

## What it does

- FB2 (also `.fb2.zip`), FB3 and EPUB 2/3: notes, images, tables, links, contents.
- Two page modes: Slide (pages) and Scroll (a continuous column), switched with `m`, keeping the line you read.
- The reading menu (`Enter`): the contents, a slider over the whole book, "Page N of M", the minutes left in the chapter.
- Footnotes over the page, internal links with a way back, search in the book (case and ё/е do not matter).
- Pictures and tables in a full-window view with zoom.
- Bookmarks, text selection from the keyboard or the mouse, highlights and quotes.
- A library of the books read, with covers; every book reopens where it was left.
- Settings as presets: theme (light or dark follows the system), font, text size, line spacing, alignment, margins.
- The interface in English and Russian; `?` lists the keys.

## Downloads

| | |
|---|---|
| Mac, Apple Silicon, macOS 14+ | `Forzac-macos-arm64.dmg` — signed ad hoc, not notarised: on the first open macOS blocks it; allow it in System Settings → Privacy & Security → Open Anyway ([step by step](https://github.com/denisfl/forzac-desktop/blob/main/docs/macos-first-open.md)) |
| Arch, Omarchy | The AUR packages are waiting for AUR registration to reopen. Meanwhile the same PKGBUILD from this repository: `git clone --depth 1 https://github.com/denisfl/forzac-desktop && cd forzac-desktop/packaging/aur/forzac-bin && makepkg -si` |
| Debian 13, Raspberry Pi OS 13 (arm64) | `forzac-linux-arm64.deb`: `sudo apt install ./forzac-linux-arm64.deb` |
| Other Linux with GTK 4.14+ | `forzac-linux-x86_64.tar.gz`, `forzac-linux-aarch64.tar.gz`: unpack and run `forzac-0.9.0-linux-<arch>/bin/forzac` |

To make Forzac the default reader on Linux:

```bash
xdg-mime default app.truenrth.forzac.desktop application/x-fictionbook+xml application/x-zip-compressed-fb2 application/x-fb3 application/epub+zip
```

Check a download with `shasum -a 256 -c --ignore-missing SHA256SUMS`.

## What was checked, and what was not

- macOS: by hand on an M1 MacBook Pro with macOS 14. The macOS 15 first-open steps follow Apple's documentation.
- Linux: the packages are built and installed in containers — Arch x86_64 (`makepkg`, the AUR packages, a run under a
  headless sway) and Debian 13 (the `.deb`, a page rendered under weston). Development builds ran by hand on a
  Raspberry Pi 5 under labwc and under Hyprland; this exact build was not tried on Linux hardware, and not on an
  x86_64 Omarchy laptop. Reports from Omarchy users are very welcome in the issues.
