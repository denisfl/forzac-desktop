Forzac 0.18.0: the books and the stats, side by side.

I reworked the library window because the stats were hiding in a menu and a window of their own. Now "Books" and
"Reading stats" are two sections of one window, as on the phone, and each system places them its own way.

- **On the Mac** the switch sits in the middle of the toolbar, with "+" and the search field next to it, or Share in the
  stats. `⌘1` and `⌘2` switch, and everything is in the menu bar too.
- **On Linux** the switch is in the header, with the main menu (Settings, Keyboard Shortcuts, About) at its end. When the
  window gets narrow, half a laptop screen in Omarchy say, the switch moves to a pill at the bottom, as on the phone.
  `Ctrl+1`, `Ctrl+2`, `Ctrl+F`, `Ctrl+,` and `F10` work.
- **The theme is in Settings now**, so you can change it without opening a book. Open books change with it, on the
  same page.
- The stats got smaller, to fit a desktop window rather than a phone, and the settings' texts got shorter.
- `?` in the library shows its keys. The "⋯" menu is gone; its items are in "+", Settings and the menu bar.

## Downloads

| | |
|---|---|
| Mac, Apple Silicon, macOS 14+ | `Forzac-macos-arm64.dmg`. If you have 0.11 or later, the library offers the update itself. A first download is signed ad hoc, not notarised: allow it once in System Settings → Privacy & Security → Open Anyway ([step by step](https://github.com/denisfl/forzac-desktop/blob/main/docs/macos-first-open.md)) |
| Arch, Omarchy | The AUR packages are waiting for AUR registration to reopen. Meanwhile the same PKGBUILD from this repository: `git clone --depth 1 https://github.com/denisfl/forzac-desktop && cd forzac-desktop/packaging/aur/forzac-bin && makepkg -si` |
| Debian 13, Raspberry Pi OS 13 (arm64) | `forzac-linux-arm64.deb`: `sudo apt install ./forzac-linux-arm64.deb` |
| Other Linux with GTK 4.14+ | `forzac-linux-x86_64.tar.gz`, `forzac-linux-aarch64.tar.gz`: unpack and run `forzac-0.18.0-linux-<arch>/bin/forzac` |

Check a download with `shasum -a 256 -c --ignore-missing SHA256SUMS`.

## What was checked, and what was not

- Not tried yet: Omarchy on hardware with tiled windows, the Raspberry Pi 5.
