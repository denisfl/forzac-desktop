Forzac 0.17.0: how you read this month.

At the end of a month it is nice to look back: how many evenings went to books, and which ones you finished. The
library now has "Reading stats" (press `s`, or find it in the "⋯" menu). Pick a month or a year and you get a calendar
with each day shaded by how long you read, the hours, the books finished, the days with a book, and the finished books
themselves. Click a day and it tells you: "18 October · 52 min".

For now the stats count what you read on this computer. Computers sharing a sync folder already add up their time;
the phone joins with a coming version of the Android app, and then a book finished on both counts once. The calendar
fills from now on: earlier versions kept no log on this computer.

On the Mac the share button makes a 1080 × 1920 picture of the month, for a story or a chat; on Linux it saves the
picture. And the end page of a book now says how it went, "6 h · 12 days · 7 highlights", with the month under it
opening the stats.

## Downloads

| | |
|---|---|
| Mac, Apple Silicon, macOS 14+ | `Forzac-macos-arm64.dmg`. If you have 0.11 or later, the library offers the update itself. A first download is signed ad hoc, not notarised: allow it once in System Settings → Privacy & Security → Open Anyway ([step by step](https://github.com/denisfl/forzac-desktop/blob/main/docs/macos-first-open.md)) |
| Arch, Omarchy | The AUR packages are waiting for AUR registration to reopen. Meanwhile the same PKGBUILD from this repository: `git clone --depth 1 https://github.com/denisfl/forzac-desktop && cd forzac-desktop/packaging/aur/forzac-bin && makepkg -si` |
| Debian 13, Raspberry Pi OS 13 (arm64) | `forzac-linux-arm64.deb`: `sudo apt install ./forzac-linux-arm64.deb` |
| Other Linux with GTK 4.14+ | `forzac-linux-x86_64.tar.gz`, `forzac-linux-aarch64.tar.gz`: unpack and run `forzac-0.17.0-linux-<arch>/bin/forzac` |

Check a download with `shasum -a 256 -c --ignore-missing SHA256SUMS`.

## What was checked, and what was not

- Core tests, both shells built and linted by CI; the stats looked at by hand on the M1 MacBook Pro.
- Not measured on the Raspberry Pi 5: the stats window's opening time and page turns with the log running.
