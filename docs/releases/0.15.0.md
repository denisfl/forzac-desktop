Forzac 0.15.0: plain text and Markdown books.

You probably have a few books that are just text: a `.txt` someone sent you years ago, notes in Markdown, a
README long enough to read on the couch. Until now Forzac shrugged at them. Now it opens them like any other book —
with hyphenation, justified lines and your theme.

- **Markdown** (`.md`, `.markdown`): headings become chapters and the contents, and italics, bold, quotes, lists,
  tables and links look the way they should. Checklists show real boxes, ticked ones a little greyed out. Pictures
  can't come along in a single file, but their captions do.
- **Plain text** (`.txt`): paragraphs are found by blank lines or indents, and lines like "Глава 1" or "Chapter I"
  start chapters. Old Russian files in windows-1251 open too.
- Open them the usual ways: `⌘O` / `Ctrl+O`, a drop on the library, Finder or the file manager. On the Mac, Forzac
  shows up in "Open With" for text and Markdown without taking them over.
- A book without a title is now named after its file, not "Forzac".

Text and Markdown files you put into the Books folder show up in the library. Adding a whole folder still picks only
books, otherwise every README in your home folder would come along :)

## Downloads

| | |
|---|---|
| Mac, Apple Silicon, macOS 14+ | `Forzac-macos-arm64.dmg`. If you have 0.11 or later, the library offers the update itself. A first download is signed ad hoc, not notarised: allow it once in System Settings → Privacy & Security → Open Anyway ([step by step](https://github.com/denisfl/forzac-desktop/blob/main/docs/macos-first-open.md)) |
| Arch, Omarchy | The AUR packages are waiting for AUR registration to reopen. Meanwhile the same PKGBUILD from this repository: `git clone --depth 1 https://github.com/denisfl/forzac-desktop && cd forzac-desktop/packaging/aur/forzac-bin && makepkg -si` |
| Debian 13, Raspberry Pi OS 13 (arm64) | `forzac-linux-arm64.deb`: `sudo apt install ./forzac-linux-arm64.deb` |
| Other Linux with GTK 4.14+ | `forzac-linux-x86_64.tar.gz`, `forzac-linux-aarch64.tar.gz`: unpack and run `forzac-0.15.0-linux-<arch>/bin/forzac` |

Check a download with `shasum -a 256 -c --ignore-missing SHA256SUMS`.
