Forzac 0.20.1: check for updates when you want to.

Forzac looks for a new version at most once a day, so a release that came out an hour after the last look waited until
tomorrow. Now you can ask at once.

- **Check for Updates…** in the Forzac menu on the Mac and in the library's menu on Linux (not in the Raspberry Pi OS
  and AUR packages, which the system updates). It says whether a new version is out and offers to install it on the
  Mac or to download it on Linux; it offers again a version you closed with "×".
- The update line in the library reads as a sentence: "Version 0.20.1 is out. Install" ("Download" on Linux).

## Downloads

| | |
|---|---|
| Mac, Apple Silicon, macOS 14+ | `Forzac-macos-arm64.dmg`. If you have 0.11 or later, the library offers the update itself. A first download is signed ad hoc, not notarised: allow it once in System Settings → Privacy & Security → Open Anyway ([step by step](https://github.com/denisfl/forzac-desktop/blob/main/docs/macos-first-open.md)) |
| Arch, Omarchy | The AUR packages are waiting for AUR registration to reopen. Meanwhile the same PKGBUILD from this repository: `git clone --depth 1 https://github.com/denisfl/forzac-desktop && cd forzac-desktop/packaging/aur/forzac-bin && makepkg -si` |
| Debian 13, Raspberry Pi OS 13 (arm64) | `forzac-linux-arm64.deb`: `sudo apt install ./forzac-linux-arm64.deb` |
| Other Linux with GTK 4.14+ | `forzac-linux-x86_64.tar.gz`, `forzac-linux-aarch64.tar.gz`: unpack and run `forzac-0.20.1-linux-<arch>/bin/forzac` |

Check a download with `shasum -a 256 -c --ignore-missing SHA256SUMS`.
