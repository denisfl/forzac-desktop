Forzac 0.11.0: two pages side by side, and on the Mac updates install from the library.

## What is new

- **Two-page spread.** In "Slide", when the window is wider than tall and each half holds a comfortable text column,
  the book shows two pages side by side, like an open book; turning moves by a spread. Each page keeps its own page
  number; notes, links, search, the selection and bookmarks work on both. Every chapter starts on the left page.
  Resizing the window into or out of the spread keeps your place. "Scroll" stays one column. No new settings.
- **macOS: updates install from the library.** When a new version is out, the library's line reads "Version N is out —
  install"; a click downloads it, checks its signature, replaces the app and restarts it. If it cannot install (the app
  runs from the disk image or from a folder you cannot write to), the line offers the download instead.
  **This version is installed by hand once**: 0.10.x cannot install updates itself yet.
- Linux: updates still come from the package manager or a new download; the library's line is unchanged.

## Downloads

| | |
|---|---|
| Mac, Apple Silicon, macOS 14+ | `Forzac-macos-arm64.dmg` — signed ad hoc, not notarised: on the first open macOS blocks it; allow it in System Settings → Privacy & Security → Open Anyway ([step by step](https://github.com/denisfl/forzac-desktop/blob/main/docs/macos-first-open.md)) |
| Arch, Omarchy | The AUR packages are waiting for AUR registration to reopen. Meanwhile the same PKGBUILD from this repository: `git clone --depth 1 https://github.com/denisfl/forzac-desktop && cd forzac-desktop/packaging/aur/forzac-bin && makepkg -si` |
| Debian 13, Raspberry Pi OS 13 (arm64) | `forzac-linux-arm64.deb`: `sudo apt install ./forzac-linux-arm64.deb` |
| Other Linux with GTK 4.14+ | `forzac-linux-x86_64.tar.gz`, `forzac-linux-aarch64.tar.gz`: unpack and run `forzac-0.11.0-linux-<arch>/bin/forzac` |

Check a download with `shasum -a 256 -c --ignore-missing SHA256SUMS`.

## What was checked, and what was not

- macOS: the spread on an M1 MacBook Pro with macOS 14, full screen; installing an update from a local appcast as
  `docs/publishing.md` describes. The first real update through this release's appcast happens with the next version.
- Linux: built, linted and tested by CI; the spread's frame timing on a Raspberry Pi 5 was not measured for this
  release.
