Forzac 0.19.0: a tidier reading panel.

The reading settings (`s` in a book) are laid out again, the same as on the phone and the web reader. Every row runs
from edge to edge in equal cells, a label sits above each setting, and what is selected is a soft highlight instead of
a black fill.

- **Themes** are six cards with the theme's paper and ink; the chosen one's name is in the label.
- **Size** is two "A" buttons, without the number.
- **Margins now make a visible difference**: 4, 7 or 13 % of the page, and in a wide window they set the line's length
  (38, 34 or 30 em). Pages lay out a little differently than in 0.18; your place in the book is kept.

## Downloads

| | |
|---|---|
| Mac, Apple Silicon, macOS 14+ | `Forzac-macos-arm64.dmg`. If you have 0.11 or later, the library offers the update itself. A first download is signed ad hoc, not notarised: allow it once in System Settings → Privacy & Security → Open Anyway ([step by step](https://github.com/denisfl/forzac-desktop/blob/main/docs/macos-first-open.md)) |
| Arch, Omarchy | The AUR packages are waiting for AUR registration to reopen. Meanwhile the same PKGBUILD from this repository: `git clone --depth 1 https://github.com/denisfl/forzac-desktop && cd forzac-desktop/packaging/aur/forzac-bin && makepkg -si` |
| Debian 13, Raspberry Pi OS 13 (arm64) | `forzac-linux-arm64.deb`: `sudo apt install ./forzac-linux-arm64.deb` |
| Other Linux with GTK 4.14+ | `forzac-linux-x86_64.tar.gz`, `forzac-linux-aarch64.tar.gz`: unpack and run `forzac-0.19.0-linux-<arch>/bin/forzac` |

Check a download with `shasum -a 256 -c --ignore-missing SHA256SUMS`.
